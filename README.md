# Exchange Diary｜交換心情，寫下生活

給你和戀人的交換日記本。把你們的日記貼進來，排成一頁頁的跨頁，加上照片、便利貼和貼紙，
再存成圖片、PDF、翻書網頁，或做成可以送印的書。

**開始使用：** https://liviaaaforfun.github.io/exchange-diary/

## 日記只存在你的裝置

- 日記、照片和設定都存在你這台裝置的瀏覽器裡，不會上傳到任何伺服器，作者也看不到。
- 清除瀏覽器資料、使用無痕模式、換手機或電腦，資料都可能消失而且無法救回。
  請定期用「備份 → 匯出備份檔」存一份。
- 這個工具免費提供，照現況使用；資料遺失或損壞，作者無法負責，也沒有辦法幫你找回。

## 功能

- 一次交換一個跨頁：左頁是他、右頁是我；四種風格（法式鄉村、粉彩文具、日系生活誌、文學報刊）
- 貼上整段日記自動分欄；選字可加粗、刪除線、換色、螢光筆
- 照片（拍立得等四種框）、便利貼、紙膠帶、自訂貼紙
- 讀日記（翻書）、翻照片（照片牆）、全書搜尋
- 輸出：PNG、PDF、翻書網頁；印刷用 PDF（A5／B6、膠裝或騎馬釘、出血、裁切標記、封面與書背）
- 手機：底部設定面板、點兩下放大書寫、兩指縮放旋轉
- 淺色／深色外觀
